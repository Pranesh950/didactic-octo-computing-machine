# StartupWiki Terminal

AI-native startup intelligence platform for venture capital investors.

Built with a Linear-inspired B2B dark terminal aesthetic.

## Quick Start

```bash
npm install
npm run dev
```

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| ⌘K | Open command palette |
| ⌘1-5 | Navigate sidebar pages |
| ↑↓ | Navigate command results |
| ↵ | Select command result |
| Esc | Close command palette |

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS (custom dark palette)
- React Router DOM
- Lucide Icons
